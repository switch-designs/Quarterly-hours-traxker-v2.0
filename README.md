# Quarterly Hours Tracker v2.0 — Custom Hour Limits

## GitHub Pages
1. Extract this ZIP.
2. Upload `index.html` and `.nojekyll` to the root of your GitHub repository.
3. In repository Settings → Pages, select the `main` branch and `/ (root)`.
4. Open the published HTTPS Pages URL to test.

## What's new
- Registration asks for each location's allowed weekly, biweekly, and quarterly hours.
- Registration asks for the administrator's personal quarterly hour target.
- The location's quarterly target controls its displayed quarter-remaining amount and bonus calculation.
- Weekly and biweekly allowances are shown in each location's tracking notice.
- These are tracking targets only; entries are not blocked for exceeding them.
- Existing location add/delete behavior, PTO calculations, and tabs are preserved.

## Data note
Tracker data is stored locally in the browser/WebView. Use Backup Data before replacing a live version, and keep a separate copy of your current working file.
